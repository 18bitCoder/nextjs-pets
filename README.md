# nextjs-pets

Pet adoption web app built with Next.js and deployed on Vercel.

## Tech Stack

- Next.js (React)
- JavaScript (ES6+)
- CSS

## Features

- Browse available pets
- Real-time chat
- Live on Vercel

## Live Demo

https://nextjs-pets-mocha.vercel.app

## Getting Started

1. Clone the repo
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000
